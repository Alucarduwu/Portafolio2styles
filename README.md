## 🧩 Description | Descripción

**EN 🇺🇸**  
This portfolio is a **highly interactive and visually-driven platform** designed to showcase full-stack development skills through a modern UI/UX experience.  

It combines performance, animation, and creative design to deliver a unique developer identity.

**ES 🇲🇽**  
Este portafolio es una **plataforma altamente interactiva y visual** diseñada para mostrar habilidades full-stack mediante una experiencia moderna de UI/UX.  

Combina rendimiento, animaciones y diseño creativo para transmitir una identidad única como desarrolladora.
